*Group Project*

**Technologies:** Python · Flask · OpenCV · MediaPipe

#### Onoma Trace — Name Origin & Nationality Classifier

*Group Project*

An NLP system that predicts country of origin from romanized names across 104 countries using character-level TF-IDF and machine learning models.

**Technologies:** Python · scikit-learn · Pandas · NumPy · Gradio
